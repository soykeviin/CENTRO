# Changelog

## 1.0.0

First public release.

- Project dashboard with categories, favorites, recents, stack and git detection.
- Menu bar search: find a project and open it with one click (Claude Code, Finder, CENTRO and more).
- Configurable launchers for cards and menu bar search, custom shell actions.
- Claude Code command setting (default `claude --dangerously-skip-permissions`), Terminal or iTerm2.
- First launch welcome with language (English, Spanish) and preferences.
- Activity, daily digest, outdated npm deps, time tracking, tasks, inbox, GitHub clone and publish.
- Automatic backup of all data on every launch.
- Performance: icons and git commands never run on the main thread; no freezes with hundreds of projects or iCloud folders.
